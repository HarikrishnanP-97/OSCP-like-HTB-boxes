- on botton we see that the site is powered by nibbleblog, which is an opensource engine for creating blogs using php 
- we can run this offline to check for vulnerabilities and also since its opensource we can search google for reported vulnerabilities  
- in order to search for vulnerabilities we need to find the version info for this 
- run a directory bruteforce against this to identify the version info and we got a readme 
- the readme file tells us that the version is 4.0.3
- we search for nibbleblog 4.0.3 exploit in google and found a shell upload vulnerabilitybut we do need admin credentials for this 
- so we need to find credentials first 
- the admin login page can be found in admin.php
- tried random credentials and got myself blocked from the site 
- ip based blocking 
- we can try local port forwarding to bypass this 
- create an ssh key for myself
- and we can perform port forwarding using the command 

	ssh -i root.key -L9000:10.10.10.75:80 10.10.14.74
	
- this will redirect all the site traffic towards our localhost on port 9000
- we can access the site on localhost:9000
